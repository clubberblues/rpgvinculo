# SQL de verificação

Arquivos SQL de conferência/evidência do catálogo SRD 3.5. Eles não são migrações versionadas e foram retirados de `supabase/migrations` para que não sejam confundidos com mudanças de esquema.

Não executar em produção sem revisar o objetivo e os efeitos de cada arquivo. As evidências podem ser consultadas e os arquivos permanecem preservados.
